# Future work

## One-click translation model installation

Offer a model catalog so users can compare, download, verify and activate translation models without manually finding files or configuring their engines. Support models from their respective original sources, including Hugging Face and other model catalogs where available. Explore automated discovery and model metadata adapters rather than maintaining every download by hand. Keep the installation experience simple even when model sources and runtimes differ.
