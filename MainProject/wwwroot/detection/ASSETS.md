# Offline language detection assets

These assets are local production dependencies. No Node.js runtime or network service is used during detection.

- Firefox CLD2: original `cld-worker.js` and `.mem` from mozilla-firefox/firefox, MPL-2.0 integration and upstream CLD2 Apache-2.0.
- MediaPipe tasks-text 1.2.0: original browser bundle and SIMD WebAssembly, Apache-2.0; model `language_detector/float32/1`, extracted without transformation from Panlingo.LanguageIdentification.MediaPipe 0.8.2's embedded default model.
- fastText: @echogarden/fasttext-wasm 0.1.0, supplied native WebAssembly and generated wrapper; MIT. Model `lid.176.ftz` from Meta's official distribution, CC-BY-SA-3.0.
- TinyLD 1.3.4 normal/light: MIT, bundled from supplied JavaScript.
- franc-min 6.2.0 and dependencies: MIT, bundled from supplied JavaScript.
- cld3-asm 4.0.0: original Google CLD3 via supplied browser WebAssembly bundle; Google Apache-2.0 and wrapper MIT.

Model/source hashes and original URLs are retained in `Archive/OfflineTranslation/LanguageDetection/Results/model-hashes.json` and `sources-and-related-models.json`. The production bundles are generated by `scripts/BuildDetectorAssets.mjs` with esbuild. No model conversion or inference implementation is involved.
