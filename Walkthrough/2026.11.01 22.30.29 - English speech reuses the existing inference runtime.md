# English speech reuses the existing inference runtime

The supplied 9.71 MB Paradee demo depended on an external native ONNX runtime. The application instead runs its original model with the ONNX Web runtime already distributed for Töz, while a small Windows service supplies the same eSpeak-to-Misaki pronunciation path. Static asset compression is excluded for the model to avoid shipping duplicate weights. New payload files total about 9.77 MB; the measured complete payload delta against 1.1.0 is about 6.74 MB.

Actual native pronunciation plus original model inference produced audio. Controlled consumers verified cached playback, alternating speeds, interruption and stale-worker rejection. The local signed 1.2.0 was opened for a native listening trial; an automated synthesis check is not a subjective listening result. See [English speech](../Docs/English-Speech.md) for ownership, events, cache lifetime and packaging.
