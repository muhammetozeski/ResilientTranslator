# Reuse template controls without replacing the approved appearance

The user requested architectural migration to MyMauiBlazorWebTemplate with the existing translator appearance and behavior preserved. Root layout/style/theme connections and PageBase are now active. Home and Settings use the extended CoreInput, CoreButton/IconButton, Stack and CoreModal contracts. Palette and dimensions live in the C# design centers, and application identity has one Constants/AppConstants source. Domain request ownership/cancellation and the supplied translation engine remain unchanged.

Actual component renderings matched before/after images at 1000 by 560 and 500 by 400 pixels. Include the host body background in such comparisons: omitting it creates a false corner-color difference around the rounded frame. Controlled checks covered rapid input while an older action awaited, stale completion rejection, native command attributes, modal close, typed editor-color changes and component-state preservation. The running application exposed actual input-editor keyboard focus, and the user confirmed the local controls and settings behaved correctly.

Account/Firebase scaffolds and duplicate direct compiler dependencies were removed; the navigation generator gained a single-page anonymous-object form while retaining named tuples. General reusable controls remain available. See [Architecture](../Docs/Architecture.md).

During local deployment, an immediate whole-directory move failed on a file lock. A complete forced copy followed by comparison of expected payload files and archival of 47 obsolete files completed the update. Deployment now waits for the exact installed application process to exit before copying. UserData and AppCache were preserved. Superseded files and test fixtures are under the designated temporary workspace.

Publication is still held at the user's request. This is a local 1.0.0 candidate; no release upload or source push was performed. The previously requested post-release package/build cleanup remains pending publication approval.
