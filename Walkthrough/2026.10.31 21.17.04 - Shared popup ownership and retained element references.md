# Shared popup ownership and retained element references

The local1.1.0 source now shares popup rendering between CoreModal, InfoPopover, CoreTooltip and the detector picker. Tooltip hover/focus state is C#; its former standalone JavaScript module was removed. Geometry is isolated behind retained ElementHandle objects, and native control API methods live in CoreElement. The template carries these same generic controls.

Twelve controlled cases passed with the actual template Razor/C# controls, including retained binding, replacement binding, monotonic tooltip ownership, modal markup, anchored placement near a viewport boundary and C# hover/dismiss state. Native bridge checks also passed. Source architecture inspection passed and the Windows build completed. The generic layer does not require changes to the translation engines.

Earlier .mjs production imports failed in the actual MAUI WebView; shipping the modules with .js extensions allowed the real Bergamot and Töz warmup to complete. Future browser-module assets must be checked in the host, beyond a Node worker consumer. See [architecture](../Docs/Architecture.md) and [offline translation](../Docs/Offline-Translation.md).
