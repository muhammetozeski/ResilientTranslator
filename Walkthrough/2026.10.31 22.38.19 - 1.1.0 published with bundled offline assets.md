# 1.1.0 published with bundled offline assets

Version 1.1.0 is published on GitHub. The signed portable package includes all 39 manifest-verified Bergamot/Töz model assets and all seven UI language files. GitHub reports matching file sizes and SHA-256 digests for the application ZIP, certificate trust ZIP and checksum list. The installed application already matched the verified local build; unchanged behavior checks were not repeated for packaging.

The source and v1.1.0 tag were pushed. UserData remains separate and unchanged. Temporary release ZIPs and generated project publish/bin/obj directories were recycled after upload verification. The archived prebuilt llama.cpp runtime bin directory is an input tool, not generated project output, and was retained. The cache-cleaner entry continues to include only the installed AppCache root.

See [offline translation](../Docs/Offline-Translation.md) and [preferences](../Docs/Preferences-and-Layout.md) for the feature contracts. Future model catalog work remains in [todos](../Docs/todos.md).
